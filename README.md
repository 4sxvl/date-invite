# Кое-что для тебя ♡

Маленькая страница-приглашение на свидание: бумажная открытка, конверт с сердцем и две кнопки. «Нет» убегает при каждом нажатии, а «Да» открывает детали встречи и небольшой дождь из сердечек.

Обычные HTML, CSS и JavaScript: без зависимостей, установки пакетов и сборки. Подходит для GitHub Pages, телефона, мыши и клавиатуры. Настройка уменьшения движения в системе учитывается.

## 1. Настрой приглашение

Открой **`config.js`**. Дата и место в нём — **примеры: замени их перед отправкой ссылки**.

```js
window.DATE_INVITE = {
  recipient: "Катя,", // Необязательно. Пустая строка скроет обращение.
  date: "28 ноября",
  time: "19:00",
  place: "Кофейня «Наша встреча»",
  address: "ул. Примерная, 12",
  mapUrl: "https://maps.google.com/?q=кафе", // Можно оставить пустой.
  message: "Я очень рад, что ты согласилась! Уже жду нашей встречи.",
  closing: "С меня — хороший план. С тебя — просто быть собой ♡",
};
```

Тексты записываются в кавычках, без HTML. Кавычки внутри текста удобнее писать «ёлочками». Ссылка на карту отображается только для корректного адреса с `https://` или `http://`.

Сам вопрос и подписи кнопок находятся в `index.html`, цвета — в начале `styles.css`.

## 2. Посмотри локально

Можно просто открыть **`index.html`** в браузере — сборка и сервер не обязательны.

Или запустить локальный сервер из папки проекта, если установлен Python 3:

```sh
python3 -m http.server 8000
```

Открой <http://localhost:8000>. Для остановки сервера нажми `Ctrl+C`.

## 3. Опубликуй на GitHub Pages

1. Создай пустой **публичный** репозиторий на GitHub, например `date-invite` (не добавляй README через сайт).
2. В терминале в этой папке выполни, подставив свой логин и название репозитория:

   ```sh
   git init
   git add .
   git commit -m "Add date invitation"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/date-invite.git
   git push -u origin main
   ```

3. На GitHub открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Открой **Actions → Deploy invitation to GitHub Pages**. Если первый запуск завершился ошибкой до включения Pages, нажми **Re-run all jobs**. Также можно выбрать **Run workflow → main → Run workflow**.
5. После успешного запуска ссылка появится в **Settings → Pages** и в результате задания `deploy`:

   ```text
   https://YOUR_USERNAME.github.io/date-invite/
   ```

Отправляй именно эту ссылку, не адрес репозитория. Публикация обычно занимает пару минут. Платный хостинг, домен и сервер не нужны.

### Как обновлять

Измени `config.js` или оформление, затем:

```sh
git add .
git commit -m "Update invitation"
git push
```

GitHub Actions опубликует изменения автоматически после отправки в ветку `main`.

### Вариант без GitHub Actions

Можно загрузить файлы через сайт GitHub, включая пустой `.nojekyll`, и выбрать **Settings → Pages → Deploy from a branch → main → / (root) → Save**. В этом случае не загружай `.github/workflows/deploy.yml`, чтобы не смешивать два способа публикации.

## Важно знать

- **Страница публичная.** Детали встречи можно увидеть в `config.js`, не нажимая «Да». Не размещай домашний адрес и другую приватную информацию. При необходимости оставь «Адрес я пришлю тебе лично».
- **Уведомлений нет.** Нажатие «Да» показывает поздравление только в браузере получательницы и не отправляет тебе сообщение. Никакие ответы не собираются и не сохраняются.
- Нет аналитики, cookies и внешних JS-библиотек. Для шрифтов браузер обращается к Google Fonts; без интернета используются системные шрифты. Если внешние запросы не нужны, удали три ссылки на Google Fonts из `<head>` в `index.html`.

## Файлы

```text
index.html                    Разметка и иллюстрация
styles.css                    Оформление, адаптивность и анимации
script.js                     Кнопки, переходы и сердечки
config.js                     Имя, дата, место и личный текст
.github/workflows/deploy.yml   Автопубликация на GitHub Pages
.nojekyll                     Отключение обработки Jekyll
```
